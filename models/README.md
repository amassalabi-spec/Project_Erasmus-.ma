#  Models (Le Cerveau brut LLM)

Ce dossier est destiné à héberger les **Large Language Models (LLM)** en local.

* **Fichiers `.gguf`** (ex : `Phi-3-mini-4k-instruct-q4.gguf`) : C'est le moteur d'intelligence artificielle brute téléchargé depuis des dépôts comme HuggingFace. 
* Ce fichier ne contient pas les données Erasmus+ ! Il contient uniquement l'intelligence permettant de parler, de raisonner et de formuler des phrases, qui sera ensuite combinée avec les documents du dossier `data/` via le processus RAG.

tous ce que j'ai utiliser :
comme model embedding:  sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
comme model de generation de phrase: Phi-3-mini-4k-instruct-q4.gguf
